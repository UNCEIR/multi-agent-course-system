# 公选课 CSV 数据集生成工具

这个目录是独立的数据处理模块，不属于现有电商推荐系统业务代码。

当前脚本根据截图中可识别的课程字段、公开高校通识/公选课目录的课程方向，以及规则扩展生成公选课推荐系统的 CSV 样例数据集。

- 截图来源字段：课程名称、教师、限选人数、已选人数、课程类型、课程分类、学分
- 公开资料参考字段：课程名称/课程方向/公选课类别风格
- 推断/模拟字段：上课时间、地点、课程简介、考核方式、难度、作业量、给分友好度、标签、适合人群、历年选课情况

生成命令：

```powershell
python .\course_dataset_tools\build_course_dataset.py
```

输出文件：

```text
course_dataset_tools/output/public_elective_courses.csv
```

注意：本数据集用于项目原型、推荐流程验证和答辩演示。除截图可见字段外，其余字段均为基于课程名和类别的规则推断，不应当当作真实教务数据使用。

当前输出规模：

- 500 条课程开课记录
- 40 个字段
- 课程 ID 唯一
- 人文与社会科学类、自然科学与工程技术类混合分布

公开资料参考：

- 西南财经大学通识选修课程目录
- 防灾科技学院公共选修课课程名单
- 西安文理学院公共选修课类别管理办法
- 中国科学院大学外语系公共选修课课程列表
