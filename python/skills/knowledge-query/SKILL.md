## 知识检索流程

### 1. 识别触发场景

用户需求中出现以下关键词时调用本技能：

- 制度：学校规定、校规、学分要求、毕业条件
- 手册：学生手册、培养方案、课程大纲
- 校园：奖学金、助学金、转专业、休学、宿舍
- 学业：我修过哪些课、某科成绩、平均绩点、学分
- 疑问：学校有没有 XX 政策、XX 怎么办理

### 2. 执行步骤

1. **识别知识领域**：判断用户问题属于（学籍管理 / 课程修读 / 奖助贷 / 宿舍生活 / 个人学业 / 其他）
2. **调用检索工具**：
   - 调 `query_knowledge(query, top_k=5)` 工具
   - 公开问题（制度/流程）检索学生手册公开分区
   - 个人问题（学业/成绩）检索当前登录用户私有分区（**user_id 由系统自动注入**，无需在参数里填）
3. **LLM 整合回答**：
   - 基于检索到的片段（content）生成回答
   - **必须引用来源**：`[来源: source_doc_name 第 X 页]`
   - 若检索结果不充分，明确说明知识边界，不编造
4. **呈现结果**：
   - 回答 + 引用来源
   - 如需进一步信息，引导用户明确问题

### 3. 注意事项

- **证据可追踪**：每个回答必须引用知识库来源（chunk_id、页码），无法检索到时不编造
- **隐私边界**：个人成绩单检索结果仅限当前用户本人；不得泄露其他用户信息
- **知识边界**：学生手册之外的领域性问题，告知用户知识边界
- **失败兜底**：知识库不可用时提示用户稍后重试，不走无源回答
