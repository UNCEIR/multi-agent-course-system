## 知识检索流程

### 1. 识别触发场景

用户需求中出现以下关键词时调用本技能：

- 制度：学校规定、校规、学分要求、毕业条件
- 手册：学生手册、培养方案、课程大纲
- 校园：奖学金、助学金、转专业、休学、宿舍
- 疑问：学校有没有 XX 政策、XX 怎么办理

### 2. 执行步骤

1. **识别知识领域**：判断用户问题属于哪个知识域（学籍管理/课程修读/奖助贷/宿舍生活/其他）
2. **检索知识库**：
   - 调知识库检索接口（Milvus `document_chunks` / FastGPT KB）
   - 检索学生手册 PDF 相关片段（种子数据源：广东工业大学2025年学生手册.pdf）
   - 取 top_k 相关片段（默认 5）
3. **LLM 整合回答**：
   - 基于检索结果生成回答
   - 引用来源（chunk_id / 页码回链）
   - 若检索结果不充分，说明知识边界
4. **呈现结果**：
   - 回答 + 引用来源
   - 如需进一步信息，引导用户明确问题
   - 提供相关延伸阅读建议

### 3. 注意事项

- **证据可追踪**：每个回答必须引用知识库来源（chunk_id、页码），无法检索到时不编造
- **知识边界**：学生手册之外的领域性问题（如具体课程内容），告知用户知识边界
- **失败兜底**：知识库不可用时提示用户稍后重试，不走无源回答
- **数据源**：种子数据源为广东工业大学2025年学生手册.pdf，后续可扩展
