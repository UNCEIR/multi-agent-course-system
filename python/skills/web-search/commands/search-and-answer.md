# Command: search-and-answer（搜索与作答）

## Steps
1. **提炼关键词**：从用户问题提取核心搜索词（去除口语化表达，保留限定词）。
2. 调用 `web_search(query, max_results=5)`（MCP 主路，熔断自动降级 tavily 直连）。
3. **整合回答**：
   - 摘要各结果核心信息
   - 标注来源链接（官方来源优先标注）
   - 与知识库信息交叉验证，冲突时说明
4. **无结果兜底**：搜索无结果 → 说明并给出放宽建议，不编造。

## 注意
- 时效性：结果反映当前时刻，历史信息结合知识库。
- 双失败（MCP + 直连）→ 结构化错误告知用户稍后重试。
