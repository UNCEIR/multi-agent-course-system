# Rules: no-fake（不伪造 + 两段式纪律）

1. **绝不伪造图片**：未 done 前不得声称"已生成"；MCP 不可达/任务失败 → 结构化错误告知用户，不返回占位图或编造链接。
2. **两段式纪律**：`image_generate` 只返回 task_id，**必须继续调用 `image_generate_get` 轮询**直到 done；不得把"已提交"当"已生成"。
3. **轮询上限**：`attempts_left` 归零或超过 10 次仍 generating → 告知用户"生成中，可用 task_id 稍后查询"（task_id 12h 有效），不再继续轮询。
4. **组图数量**：prompt 明确"1-3 张内容关联的组图"；force_single 默认 false（智能组图），数量由语义控制。
5. **参数规范**：prompt 用中文描述主体+场景+风格；`scale` 默认 0.7（文本遵从权重，越大越遵从语义）。
6. **结果标注**：产物转存 MinIO/本地后返回持久化链接；若转存失败返回 24h 外部 URL 需标注时效。
