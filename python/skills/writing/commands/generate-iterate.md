# Command: request-confirm（需求确认）

## Steps
1. 确认四项要素：
   - `topic`：主题（必填）
   - `genre`：体裁（学术论文/读书报告/实习报告/课程设计/演讲稿/新闻稿/散文/其他）
   - `word_count`：目标字数
   - `outline`：大纲（可选，有则更精准）
2. 要素缺失时先询问，不擅自假设。

# Command: generate-iterate（生成与迭代）

## Steps
1. 调用 `writing_assistant` 按体裁成稿（结构：引言-主体-结论，语言规范）。
2. **对话式迭代**：
   - 用户反馈 → 明确修改点（改哪段/改什么方向/字数调整）
   - 局部修改：给出修改后的对应段落，不整篇重写（除非用户要求）
   - 续写：从断点继续，衔接前文
3. 交付前自查：结构完整、体裁符合、无编造引用。
