# 大学校园智能体平台 · 简历项目经历（2026-09-06 包装定稿版）

> 用途：面试简历/口播的 8 条项目经历，与参考模板体量一致、适度包装、少括号少术语。
> 使用提示：数字口径以本会话长期记忆模板为准；被追问"怎么测出来"的展开素材见
> docs/interview-star-stories-phase4.md（2026-09-02 仓库核对版）与 docs/interview-numbers-audit-2026-09-06.md。








1. **Chat 智能体**：基于 deepagents 搭统一入口主智能体，按意图路由并派发 29 个工具，覆盖图片生成识别、学生手册公共问答、个人成绩单私有问答、网页搜索、选课推荐等多模式；用户身份由框架注入、个人数据强隔离防越权；意图链路正确率 94%，端到端真实链路路由成功率从 20% 拉到 100%、4/4 全过。
2. **Recommend 智能体**：画像/召回/重排/可行性/理由 5 个子智能体并行编排成推荐工具，硬约束前置过滤加双模式 A/B 对照；Redis 语义缓存相似度超 0.95 直接复用候选；真实链路耗时 206s 降到 60s。
3. **Report 智能体**：批量成绩 Excel 结构化解析，跨表合并加完整性校验、缺科禁渲染，并发渲染导出 PDF 存对象存储生成下载链接；真实整班端测 37 份报告全量正确、零失败。
4. **Evaluation 智能体**：反幻觉工作流——确定性数据源、结构校验、引用核验硬闸，输出数字必须可溯源，违规重试后规则兜底不静默；幻觉用例拦截率 100%，真实链路通过率 98%。
5. **RAG**：文档按标题层级递归切分，检索按权限分区，学生手册走公共库、成绩单按用户私有隔离；课程按语义拆 4 类分块打标签；检索不到如实说明，不编造来源页码。
6. **Memory 机制**：分层记忆——会话级 checkpoint 落库做短期记忆、断点可恢复；系统级知识存运行时记忆文件；用户对话自动提取偏好/事实/决定类条目，按用户隔离、改口自动合并；压缩双模板续写、失败规则截断兜底，长会话不丢上下文。
7. **LangSmith + LLM 裁判评测**：离线断言、真实端测、LLM 当裁判三层验证，8 个评测集 74 用例、22 份报告；裁判覆盖忠实度、切题度与规则，检索按 NDCG/F1 聚合、全程追踪并回写裁判结果；后端单测 446 个。
8. **流式机制**：SSE 服务端单调事件 ID 加断点续传，4 个端点统一 done/error 收尾；前端指数退避重连三次并校验完整性；端到端 P95 22.8s 优化到 14.5s，断线续传不丢事件。
