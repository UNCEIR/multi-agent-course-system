## 功能描述

论文写作助手，在 main agent 对话框中协作完成论文写作。支持多体裁/多风格写作，如课程论文、实验报告、文献综述、读后感、调研报告、开题报告等。

## 输入参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `topic` | `str` | 是 | — | 论文主题或标题，1-500 字符 |
| `genre` | `str` | 否 | `"课程论文"` | 写作体裁 |
| `outline` | `str` | 否 | `""` | 论文大纲（可选，留空则自动生成），最多 2000 字符 |
| `word_count` | `int` | 否 | `1500` | 目标字数，范围 100-50000 |

## 输出

生成的论文内容 markdown 文本。

## 失败兜底

- LLM 调用失败时返回错误信息，提示用户重试
- 支持多轮协作修改，单轮失败不丢失已生成内容
